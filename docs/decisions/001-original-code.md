# ADR-001: Original application code

Status: accepted.

OpenHubPanel's application code, visual system, components, and workflows are written for this project. Local panels are research material only; do not copy code or reproduce screens verbatim.

Maintained open-source libraries may be used with version/license records and required notices. Keep reference copies and their licenses under ignored local storage, outside source releases and Docker context. Original code does not mean reimplementing cryptography or authentication protocols.

This trades a quick theme fork for a product structure we can understand, test, and maintain.
