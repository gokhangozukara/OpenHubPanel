# Contributing to OpenHubPanel

Thanks for taking a look. OpenHubPanel is early in development, so a clear bug report or a confusing setup step is just as useful as a patch.

Read the [project status](PROJECT_STATUS.md), [development guide](docs/DEVELOPMENT.md), and [roadmap](docs/roadmap/implementation.md) before choosing work. The local preview runs today; authentication and real management are not ready for production.

## Sending a change

Keep repository content in English: names, code comments, documentation, issues, pull requests, and commit messages. Interface translations live in the English, Turkish, and German locale files. Update all three when adding visible text.

For a bug, explain what you tried, what happened, and how to reproduce it with sample data. Discuss a large feature before spending days implementing it. Small, focused pull requests are easier to review.

Describe the problem your change solves and how you checked it. Run the relevant commands in the development guide. Check links for documentation changes and include a screenshot for a visible change when it helps.

Write original implementation code and follow [AGENTS.md](AGENTS.md). Never include customer data, credentials, private server information, or local reference copies. Note new dependencies and their licenses, and submit only work you have the right to contribute.

## License and credit

Contributions submitted for inclusion are provided under the project's [MIT License](LICENSE). You retain copyright in your contributions. Preserve third-party LICENSE and NOTICE files.

Using OpenHubPanel does not require a contribution, payment, star, or publication of your modifications. We appreciate hearing how you use it and what could work better.

## Working together

Keep discussions constructive and focused on the work. Harassment, personal attacks, and sharing private information are not welcome. Maintainers may moderate discussions and decline changes outside the project's scope.

Report vulnerabilities privately through [SECURITY.md](SECURITY.md).
